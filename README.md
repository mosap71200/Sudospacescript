## 📖 نبذة عن السكربت

سكربت **SudoSpace** هو أداة تثبيت آلية لأنظمة التشغيل عبر **udocker**، حيث يمكنك تثبيت:

- 🐉 Kali Linux (موصى به)
- 🐧 Ubuntu
- 🐚 Debian

بضغطة زر واحدة، دون الحاجة إلى صلاحيات `root` أو تثبيت Docker الحقيقي!

---

## ⚙️ متطلبات التشغيل

| المتطلب | التفاصيل |
|---------|----------|
| نظام التشغيل | Linux (أي توزيعة) |
| الصلاحيات | بدون root (تشغيل عادي) |
| الاتصال بالإنترنت | مطلوب للتحميل الأولي |
| المساحة المتاحة | ~2-5 جيجابايت |

---

## 📥 طريقة التثبيت والتشغيل

```bash
# 1. تحميل السكربت
curl -O https://github.com/mosap71200/Sudospacescript.git

# 2. جعله قابلاً للتشغيل
chmod +x sudospace.sh

# 3. تشغيل السكربت
./sudospace.sh
